# Webpage With Toggleable Dark And Light Mode JavaScript

## Overview
Home webpage for a fictional game news company which displays featured articles. The main feature of this application is that the page styling can be switched between light and dark modes by the user. This was achieved using JavaScript that toggles the CSS styling used by the elements on the page when the icon in the bottom right of the page is clicked.<br>
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://toggleable-dark-and-light-mode.vercel.app/

## Tech Stack
- JavaScript
- CSS3
- HTML5
